# reasoning-based-refinement-llms-vegan

This repository contains code and data for the paper titled "[Reasoning-Based Refinement of Unsupervised Text Clusters with LLMs](https://arxiv.org/pdf/2604.07562)", [ACL 2026](https://2026.aclweb.org/)

## Necessary Libraries
The code is implemented in Python 3. 

Other major libraries needed:

Python 3.9.19

PyTorch 1.13.1

jupiter notebook

pandas

gensim

nltk

nltk.tag

spacy

emoji

sklearn

scipy

matplotlib

numpy

preprocessor

transformers

seaborn

BERTopic

tiktoken

openai

groq

mistralai
